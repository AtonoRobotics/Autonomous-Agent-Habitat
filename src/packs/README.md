# packs

Signed domain packs: identity, roles, journey kinds, action-class verbs, policy
rule bodies, connectors, record/party knowledge, evidence-eval fixtures, ask
ceilings, field language map, optional adapter allow-list and routines.

Load fails closed. Unsigned, half-signed, incomplete, or tampered packs are refused;
signatures are re-verified on every read-back; boot never generates keys.
