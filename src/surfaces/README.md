# surfaces

The two human surfaces and what each may do.

**Field** — journeys about records, held cards, the outbound tape, and a bounded
ask line. Configures nothing.

**Architect** — issues and revokes field tokens, binds the model, connectors,
skills, routines, deadlines, and mail, promotes proposals, records deploys, and
sits in the habitat: one read that returns org, the open run, workers, grants,
eval, and isolation as live records. The seat writes nothing.
