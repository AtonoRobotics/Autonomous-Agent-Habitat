# Decision records

One file per decision, numbered `DEC-NNNN-slug.md`, never renumbered. A decision
here is a constraint on the code: if a rule is worth a typed refusal, it is worth a
record, and the code comment cites it by id.

Status is `accepted`, `superseded by DEC-NNNN`, or `rejected` — rejected decisions
stay, because knowing what was refused is half the value.

Copy `TEMPLATE.md` to start one.
